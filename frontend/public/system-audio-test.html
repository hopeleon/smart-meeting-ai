系统音频捕获诊断

音量电平:
--

诊断说明

  • 点击"开始诊断"，在弹出的系统选择器中选择一个标签页（里面要有正在播放的音乐/视频）
  • 如果看到绿色的"能量值"大于 0.001 → 系统音频捕获正常
  • 如果能量始终是 0.00000000 → 你的 Windows 系统不支持 getDisplayMedia 系统音频（常见问题，需要用替代方案）

Windows 替代方案

  • 方案1: 安装 VB-Audio Virtual Cable（虚拟音频线），然后用麦克风模式录音系统声音
  • 方案2: 改用麦克风模式，让对方在会议中直接说话
  • 方案3: 使用 Edge 浏览器（Edge 对 Windows 系统音频支持更好）
